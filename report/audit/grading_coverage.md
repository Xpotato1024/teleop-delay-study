## 4. Simulink画面のスクリーンショット要否

現時点では、図1が通信モデル、3つの一次遅れプラント、参照経路および評価経路を説明し、本文5章がMATLAB/Simulinkの責務と実コードを示している。このため、課題要件が「Simulinkモデル画面そのものの掲載」を明示していない限り、スクリーンショットは必須ではない。

PDF監査後にプログラム構成が十分伝わらない場合、または教員からSimulink画面の掲載を明示的に求められた場合に限り、次の2枚を追加候補とする。

- top-level system modelの全体構成
- communication Model Reference内部のsampling、固定遅延、最新パケット選択、ZOH/CV再構成

スクリーンショットを追加する場合も、文字が読めない全画面画像を貼るのではなく、対象部分を明確にした高解像度画像と短い図題を用いる。
