# Teleoperation Delay Study

MATLAB simulation study of transport delay and constant-velocity prediction in a remote position-command system.

## Research question

Under which combinations of transport delay, trajectory speed, and trajectory shape does constant-velocity prediction reduce tracking error, and where does the compensation lose effectiveness or become worse than uncompensated zero-order hold?

Constant-velocity prediction is not claimed as a new technique. The project contribution is the reproducible comparison framework, separation of task-tracking error from delay-induced error, and search for an operating boundary rather than a single favorable example.

## Compared systems

1. Packetized command with zero transport delay
2. Delayed command with zero-order hold
3. Delayed command with constant-velocity dead reckoning

The planned plant is an axis-independent first-order response model. Circle and Lissajous trajectories form the deterministic core; optional point-to-point minimum-jerk trajectories test robustness beyond periodic motion.

## Reproducibility policy

- All simulation parameters belong in configuration data.
- Random studies record and reuse explicit seeds.
- Results and report figures are regenerated by code.
- MATLAB version, execution command, and validation status are recorded.
- Method comparisons use identical trajectory instances and evaluation windows.

## Out of scope

- human-subject experiments and subjective workload;
- real-network measurement;
- packet loss, jitter, and packet reordering;
- detailed 3D robot geometry, IK, joint limits, contact, collision, and force feedback;
- machine-learning prediction.
