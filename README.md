# 遠隔操作ロボットの通信遅延に対する定速度予測補償の有効範囲

一次遅れ・純遅延モデルを用いて、遠隔操作ロボットの軌道追従に対する定速度予測補償の有効範囲を調べるためのMATLAB研究リポジトリです。

## 研究質問

通信遅延、軌道速度、軌道形状が変化したとき、定速度予測補償はどの条件で追従誤差を改善し、どこで改善効果が失われる、または悪化するのかを明らかにします。

## 比較方式

- 遅延なし参照系
- 通信遅延あり・補償なし（ZOH）
- 通信遅延あり・定速度予測補償（Constant-Velocity dead reckoning）

主な評価指標は、通信起因の位置NRMSE、目標軌道に対する追従NRMSE、最大位置誤差、補償改善率です。

## 構成

- `run_project.m`: リポジトリルートから実行する将来の単一入口
- `src/`: 設定、検証、メイン処理のMATLABコード

- `research/`: 研究課題と判断ログ
- `docs/`: アーキテクチャ、開発方針、ロードマップ、スケルトン報告
- `report/`: 最終レポートと掲載図
- `results/`: 生成結果の保存先
- `references/`: 参考文献候補の管理方針
