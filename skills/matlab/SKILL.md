# MATLAB実務規約

このリポジトリでCodexがMATLABを扱う際の最小限の規約です。

- `run_project.m` を単一入口とする。
- パラメータは `default_config.m` に集約する。
- 関数は原則1ファイル1関数とする。
- 変数名と単位を明確にする。ベクトル・行列の次元はコメントまたは`assert`で示す。
- 入力検証には`validateattributes`または明示的な`assert`を使う。
- 乱数を使う場合は`rng(seed, "twister")`を使う。
- グラフには軸名、単位、凡例、タイトルを付ける。
- レポート掲載図はコードから再生成可能にする。
- 数値積分を実装するときは時間刻み収束性を確認する。
- MATLABが利用可能なら実行する。Octaveを使う場合はMATLAB検証の代替とはせず、代替検証と明記する。
- 実行できなかった検証を成功扱いしない。
- warningやerrorを無条件に抑制しない。
